# Harness4MIS

用于 MIS303 课程作业的本地运行工具。上传当次题目图片和相关材料后，依次完成完整题目转录、逐题作答、两轮修订、计时，以及 Word 报告和 PowerPoint 文件生成。

每次作业都从新图片中的 **Problem Statement** 开始。旧作业范例只提供组织与改进方法，具体情景、数据、问题和结论不会自动进入新作业。

## 开始使用

当前版本面向 **macOS 和本机 Codex 运行环境**。需要已安装并登录 Codex CLI，以及本机提供的 documents、presentations 文件处理组件；这些运行组件和模型账号需自行具备。

1. 下载或克隆本仓库。
2. 在文件夹中双击 `启动.command`。
3. 打开窗口显示的网址，通常为 `http://127.0.0.1:8787`。
4. 按阅读顺序选择题目图片，上传本次材料，填写作业信息，点击“开始作业”。
5. 完成后下载 Word 报告、PPT、报告附件、完整对话和时间记录。

如果启动文件没有执行权限，可在仓库目录运行：

```sh
chmod +x 启动.command
./启动.command
```

默认使用本机 Codex 登录。也可以在页面的“模型连接”中填写支持图像输入和严格 JSON 输出的 OpenAI Responses API 接口、模型名称及密钥。

更详细的操作说明见 [使用说明](使用说明.txt)。

## 作业流程

- **题目转录**：先完整呈现原语言、编号、子问题及限制条件，再拆分任务。
- **逐题回答**：按原题顺序展开直接回答、相关分析与管理含义。
- **第一轮修订**：检查题目覆盖、概念、来源、数字、计算及逻辑。
- **第二轮修订**：改善解释、可读性、例子、图表和建议。
- **报告与 PPT**：共用修订后的内容，保留完整题目，并检查页面显示。
- **暂停与继续**：保存完成部分，补充转录、说明或材料后继续处理。

正文采用自然的课程研究与商业分析语言。具体事实和命名理论在写入前核对，基础定义和前提明确的推导按其逻辑展开。提示词与原始输出另行整理，避免把制作日志写进业务分析正文。

## 输入与时间

题目图片支持 PNG、JPG 和 WebP。材料支持 DOCX、PDF、XLSX、CSV、TSV、TXT、Markdown 及图片。单次最多 30 个文件，总量不超过 40 MB。

默认根据你上传的题目与材料分析。需要外部资料时，可在页面勾选“允许查阅外部来源”。

165 分钟是单次工作预算，实际计时从开始处理题目到报告和 PPT 完成，包括暂停及等待。阶段处理时间另行记录，人工投入不由程序自动测量。程序保留老师给定的评分口径，不自动授予课程成绩或最佳实践奖励。

## 运行环境与测试

启动脚本自动查找本机 Codex 的 Python 与文件处理运行组件。可检查环境：

```sh
"$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3" run.py --doctor
```

运行流程测试：

```sh
"$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3" -m unittest discover -s tests -v
```

真实模型测试会使用当前账号的模型额度：

```sh
"$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3" -m tests.live_smoke --full
```

当前验证包括 19 项流程测试，以及使用本机 Codex 登录完成的一道小型题目的图片转录、回答、两轮修订、Word 和 PPT 生成及页面检查。独立 API 接口需要使用相应账号配置。

## 文件组织

| 路径 | 内容 |
| --- | --- |
| `run.py`、`启动.command` | 启动与环境检查 |
| `harness/` | 流程、模型连接、材料读取、内容检查及文件生成 |
| `static/` | 本机上传与进度页面 |
| `policies/` | 通用写作要求与评分口径 |
| `tests/` | 流程测试与真实模型测试入口 |

每份作业的上传副本、运行记录与生成文件保存在本机 `runs/` 中；测试生成内容保存在 `tests/work/`。这些目录已加入忽略规则。API 密钥只在服务内存中使用，重启后需要重新填写。

本项目依赖本机 Codex 文件处理运行组件，不包含这些组件本体。它还没有被打包成可独立安装的跨平台桌面应用。
